# Скрипты проекта

`local-ai/` содержит подготовку окружения, диагностику, прямые проверки моделей
и локальный просмотр результата. Они запускаются на серверном ПК отдельно от
Windows EXE и не создают законченный HTTP backend.

- [Инструкция Local AI](../docs/local-ai/README.md): порядок установки и команды.
- [Отчёт](../docs/local-ai/handoff.md): hardware, версии, модельные revisions и измерения.
- [Проверки всего проекта](../docs/verification.md): различия демо, моков и моделей.

Передайте пути моделей и записей через предусмотренные параметры/локальные
настройки. Не добавляйте токены, записи, модельные веса или полученные транскрипты
в Git. Скрипты проверки не должны отправлять эти данные внешним AI-сервисам.

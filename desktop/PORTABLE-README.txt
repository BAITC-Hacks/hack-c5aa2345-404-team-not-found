SAMRUK KAZYNA — Windows x64 portable client

Распакуйте весь архив в обычную папку. Запустите SAMRUK-KAZYNA.exe.
Папка _internal должна находиться рядом с EXE. Python, Node.js и WebView2
устанавливать не нужно: Python и движок Qt включены в архив.

Backend и модели запускаются отдельно — на этом ПК или на компьютере
участника Local AI в локальной сети. В левой панели приложения откройте
настройки подключения и укажите адрес backend, например http://192.168.1.10:8000.
Сам EXE не распознаёт речь без работающего backend с настроенными моделями.

Без backend можно явно включить деморежим с синтетическими данными,
посмотреть транскрипт и поручения, сохранить демонстрационный DOCX/PDF.

Настройки и технические журналы: %LOCALAPPDATA%\SAMRUK_KAZYNA\
Закрытие окна завершает его локальный UI-сервер, но не удалённый backend.
Сборка для Windows 10/11 x64. Сертификатом подписи не подписана.

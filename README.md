# HackAlem — локальное протоколирование совещаний

Privacy-first система для автоматического протоколирования совещаний внутри инфраструктуры организации. Цель — сократить ручную работу секретаря, сохранить поручения, сроки и ответственных в проверяемой структуре.

## Проблема

Ручное ведение протоколов занимает время и повышает риск потерять поручение, исказить срок или неправильно определить ответственного.

## Подход

Пользователь загружает аудио или видео совещания. В целевой архитектуре сервер локально создаёт транскрипт русской, казахской и смешанной речи, разделяет реплики по анонимным говорящим, формирует summary и поручения, а затем экспортирует итоговый протокол.

## Privacy-first / on-premise

Аудио и транскрипты не должны передаваться в облачные AI API. Целевая обработка выполняется локально: faster-whisper для STT, pyannote для diarization и локальная LLM через Ollama или llama.cpp. Модели и записи не хранятся в Git.

## Текущий статус: подготовительный каркас

**Уже подготовлено:**

- структура FastAPI backend;
- схемы транскрипта, реплик и поручений;
- абстрактные интерфейсы STT, diarization, local LLM и экспорта;
- placeholder-реализации, которые не загружают модели и не обращаются к внешним сервисам;
- примеры mixed ru/kk транскрипта и ожидаемого результата;
- конфигурационный шаблон и документация архитектуры.

**Ещё не реализовано:**

- обработка аудио/видео;
- faster-whisper, pyannote и локальная LLM;
- загрузка файлов и хранение результатов;
- DOCX/PDF экспорт;
- база данных, аутентификация, напоминания, Teams/Zoom/Google Meet, mobile и Docker.

На этом этапе зависимости и модели **не устанавливались**, модели **не скачивались**, AI pipeline **не запускался**.

## Предполагаемый стек

- Python 3.11, FastAPI, Pydantic, Uvicorn;
- FFmpeg для подготовки аудио;
- faster-whisper с Whisper large-v3 или large-v3-turbo;
- pyannote/speaker-diarization-community-1;
- Qwen3 через Ollama или llama.cpp;
- SQLite для MVP, PostgreSQL позднее;
- python-docx и PDF-библиотека для экспорта.

## Структура

```text
backend/
  app/
    api/             # будущие HTTP-границы
    core/            # конфигурация и ошибки
    models/          # внутренние доменные модели
    schemas/         # API-схемы Pydantic
    services/        # контракты STT, diarization, LLM и экспорта
  tests/
  requirements.txt   # планируемые, но не установленные зависимости
samples/             # безопасные JSON-примеры без записей людей
docs/                # архитектура и принципы
scripts/             # место для будущих setup-скриптов
```

Подробнее: [docs/architecture.md](docs/architecture.md) и [ROADMAP.md](ROADMAP.md).

## Roadmap

1. Согласовать оборудование и тестовые данные с уведомлением участников.
2. Установить и сравнить локальные STT-модели на русско-казахской речи.
3. Добавить diarization и объединение по timestamps.
4. Подключить локальную LLM, извлечение поручений и валидацию JSON.
5. Реализовать экспорт, API, хранение и пользовательский интерфейс.

# Derek — помощник медицинской комиссии

Демонстрационный frontend-прототип для подготовки и проверки дел медицинской комиссии. Он собирает историю пациента, документы, расхождения и ключевые изменения в одной понятной рабочей среде.

> Все пациенты, медицинские сведения и документы в проекте вымышлены. Это интерфейсный прототип без backend, внешних API и реальных персональных данных.

## Демо

Открыть сайт: **[wthman2.github.io/derek-medical-commission-demo](https://wthman2.github.io/derek-medical-commission-demo/)**

## Что реализовано

- обзор работы комиссии и очередь дел;
- поиск, сортировка и фильтры пациентов;
- карточка дела с фактами, показателями и документами;
- интерактивная история болезни и фильтрация событий;
- локальная имитация AI-анализа с проверяемыми источниками;
- сравнение двух освидетельствований МСЭ;
- реестр документов, просмотр источников и досье комиссии;
- печать и скачивание демонстрационного отчёта;
- адаптивная версия для мобильных устройств и базовая accessibility-поддержка.

## Стек

React · Vite · TypeScript · React Router · Tailwind CSS · shadcn/ui · Radix UI · Motion · Lucide

## Структура проекта

```text
src/
├── components/  # общие и shadcn/ui-компоненты
├── data/        # локальные демонстрационные данные
├── layouts/     # оболочки рабочего пространства и дела
├── lib/         # вспомогательная логика
├── pages/       # экраны приложения
└── types/       # TypeScript-типы

public/          # статические файлы и обработка ссылок GitHub Pages
docs/            # описание архитектуры
.github/         # автоматическая публикация в GitHub Pages
```

Подробности: [архитектура проекта](docs/ARCHITECTURE.md).

## Локальный запуск

```bash
npm install
npm run dev
```

После запуска откройте `http://127.0.0.1:5173`.

## Проверка проекта

```bash
npm run typecheck
npm run lint
npm run build
```

Публикация в GitHub Pages выполняется автоматически после каждого push в ветку `main` через [workflow](.github/workflows/deploy-pages.yml).

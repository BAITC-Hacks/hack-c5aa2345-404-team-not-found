# Критерии и чек-лист сдачи

Основание — таблица критериев, переданная участником команды, и требование
организаторов о самостоятельном запуске и понимании проекта жюри.
Вес: работоспособность 25, техника 25, README/воспроизводимость 25,
ценность 15, развитие/оригинальность 10; всего 100. Оценки проекту здесь не выставляются.

- [ ] Воспроизвести инструкции на чистой машине и записать commit/версии.
- [ ] Подготовить разрешённую запись и эталон; записи не включать в Git.

## Функциональная приёмка полного решения

- [ ] Запись загружается через native EXE; backend создаёт задание и хранит результат.
- [ ] STT/диаризация/LLM действительно вызываются серверным пайплайном.
- [ ] RU/KK-текст, говорящие и timestamps сверены с аудио.
- [ ] Поручения и источники сверены с эталоном, неизвестные поля не придуманы.
- [ ] Реальные DOCX/PDF соответствуют результату.
- [ ] Полный сценарий работает без внешнего интернета после скачивания моделей.
- [ ] Зафиксированы время, память, качество и ограничения.

Отмеченные пункты о документах означают наличие материалов, а не успешное
прохождение функциональной приёмки. [Команды и прежние результаты](verification.md).

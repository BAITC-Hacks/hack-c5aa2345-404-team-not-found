- [ ] EXE-клиент запускается без установленного Python/Node.js и ручного запуска UI-сервера; требования отдельного backend описаны.
- [ ] Приложение показывает доступность выбранного backend и ошибки подключения.
- [ ] Запись загружается, стадия обработки обновляется.
- [ ] Русский, казахский и смешанный текст сохраняются с временными метками.
- [ ] Реплики различаются по говорящим; анонимные speaker ID не выдаются за установленные личности.
- [ ] Поручения имеют проверяемый источник; неизвестные имена и сроки не выдуманы.
- [ ] DOCX/PDF открываются и соответствуют результатам встречи.
- [ ] После скачивания моделей аудио и текст обрабатываются локально.
- [ ] Модели, реальные записи, токены и ключи подписи отсутствуют в Git.

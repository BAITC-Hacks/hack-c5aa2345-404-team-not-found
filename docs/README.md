# Документация SAMRUK KAZYNA

Документы объединяют опубликованные отчёты команды от 23.09.2026 и текущую
backend-интеграцию: все маршруты API, очередь, хранение, локальные адаптеры и
DOCX/PDF реализованы. Health сообщает `ok`/`not_ready`, неготовая загрузка — HTTP 503.
Пройдены 22 backend-, 43 Local AI-проверки и 10 проверок native-клиента с настоящим
API при подменённых моделях. Сквозной GPU-сценарий с настоящими моделями ещё не подтверждён.

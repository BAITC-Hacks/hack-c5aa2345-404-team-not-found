## Native-клиент: сборка и проверки без AI

Нужны Windows x64/.NET, системный C#-компилятор Framework64 и Python 3.11
для тестового HTTP-сервера. Сам проверяющий runner собирает x64-harness;
основной EXE собирается с AnyCPU.
Python нужен тестовому инструменту, а не самому EXE. Из корня:

```powershell
.\desktop\build-native.ps1
py -3.11 desktop/tests/run-native-checks.py
```

Скрипт запускает временный loopback HTTP-сервер, компилирует вспомогательный
C#-проверяющий код и использует собранную assembly. Результаты находятся в
`desktop/build/native-tests/`. Это не GUI-автоматизация и не нейросетевая обработка.
Само окно и сохранённый DOCX проверяйте по [сценарию жюри](jury-guide.md).

## Интегрированный backend

Команды запуска на готовом компьютере моделей: [backend-launch.md](backend-launch.md).
Для API и экспортов нужны зависимости из `backend/requirements-runtime.txt`.
`GET /health` возвращает 200 и `ok` либо `not_ready`; список встреч доступен через
`GET /api/meetings`. Загрузка требует готовых ресурсов: 202 при приёме либо 503,
если модели/FFmpeg/экспорт недоступны. Методы состояния, результата и экспорта
реализованы. До завершения обработки результат/экспорт возвращают 409.

После подготовки Python-окружения из корня репозитория:

```powershell
Push-Location backend
.\.venv\Scripts\python.exe -m unittest discover -s tests -p test_backend_api.py -v
.\.venv\Scripts\python.exe -m unittest discover -s tests -p test_pipeline.py -v
Pop-Location
.\backend\.venv\Scripts\python.exe backend/tests/run_native_api_check.py
```

Последняя команда требует ранее собранный `desktop/release/SAMRUK-KAZYNA.exe`.
Она поднимает настоящий временный Uvicorn/FastAPI и использует синтетическую запись,
подменяя только FFmpeg, readiness и модели. Отчёт сохраняется в
`desktop/build/native-real-api-check/`; отдельный каталог SQLite удаляется после теста.
Тесты моделей не скачивают веса и не отправляют данные во внешние API.

## Local AI

[Инструкция моделей](local-ai/README.md) содержит подготовку окружения и точные
команды автономных тестов и модельной диагностики. Для запуска моделей используйте
AI-окружение. Для 43 тестов с заглушками можно отдельно установить только лёгкие
зависимости (версии из отчёта команды), без Torch и весов:

```powershell
py -3.11 -m venv work/verification-venv
.\work\verification-venv\Scripts\python.exe -m pip install pydantic==2.10.5 httpx==0.28.1 soundfile==0.13.1
Push-Location backend
try {
    & ..\work\verification-venv\Scripts\python.exe -m unittest discover -s tests/local_ai -v
    if ($LASTEXITCODE -ne 0) { throw 'Local AI checks failed' }
} finally { Pop-Location }
```

Команды выполняются из корня репозитория. Установку пакетов продолжайте только
при успешном exit-коде. Это отдельное тестовое окружение, а не сервер моделей;
новая чистая установка в рамках документационного аудита не проверялась.

Для модели нужно записать hardware, package versions, model revision, язык,
продолжительность фрагмента, время/память, offline-условия и наблюдённые ошибки.
Сравнение с отредактированным протоколом PDF не заменяет эталонную расшифровку.

В обновлении Local AI появился `scripts/local-ai/evaluate-meeting.py`: извлечение
PDF, нормализация аудио, STT, диаризация, сравнение, анализ и локальный HTML-отчёт.
Его новая версия проверена 14 автономными тестами, но ещё не прошла все этапы
на реальной записи. Исторические времена полной записи относятся к предыдущему
локальному скрипту. Для нового прогона используйте [инструкцию Local AI](local-ai/README.md).

В отдельной расширенной проверке Qwen строгие критерии прошли в **12 из 14**
синтетических прогонов. Это зафиксированное ограничение, а не 100% качество LLM.

## Прежний Streamlit

Существуют два исторических отчёта с одинаковым числом «14»:

- `160d1e0`: 7 тестов старого backend, 4 состояния UI и 3 редактора.
- Desktop handoff: 7 настроек Streamlit, 4 состояния UI и 3 редактора.

Они относятся к разным наборам и не являются проверкой native EXE. Исторический
корневой `tests/test_backend_api.py` импортирует прежний `backend.app.agent`.
Актуальные проверки находятся в **`backend/tests/`**: запускайте команды выше
из указанного рабочего каталога. Уточнения — [Streamlit README](../frontend/README.md).

## Что остаётся подтвердить

- полный путь EXE → HTTP → реальные модели → Result → DOCX/PDF на ПК Local AI;
- соответствие реальных поручений и экспортов исходной записи при ручной проверке;
- качество RU, KK и mixed-речи на согласованном эталоне;
- полный путь без внешнего интернета после установки моделей;
- запуск EXE на другом Windows-ПК, повторный запуск с сохранёнными настройками;
- корректность длительных записей, отмены/восстановления и ограничений памяти.

План работ и критерии завершения: [ROADMAP](../ROADMAP.md).

# Задания для двух участников

Эти промпты дополняют инструкции репозитория. Отправь соответствующий текст в существующую сессию Codex друга. Используй один официальный репозиторий; новые репозитории для частей проекта не создавай.

## Участник Local AI — продолжение уже начатой установки

```text
Это уточнение текущей задачи HackAlem. Продолжай уже начатую установку и загрузку локальных моделей, сохрани прогресс.

Нас трое: Medet отвечает за backend и интеграцию; ты — за Local AI; третий участник — за Android APK. Официальный репозиторий: https://github.com/BAITC-Hacks/hack-c5aa2345-404-team-not-found.

Проверь remote по URL, получи актуальный main через fetch и прочитай AGENTS.md, README.md, docs/team-workflow.md, docs/api-contract.md и существующие base.py в backend/app/services. Если есть незавершённые изменения, сохрани их в своей ветке; сначала можно читать новые документы через git show <team-remote>/main:<path>. Не сбрасывай работу ради обновления.

Рабочая ветка codex/local-ai-setup. Установки и скачивание моделей на этом компьютере разрешены прежним заданием. Проверь железо и выбери подходящие Whisper через faster-whisper, pyannote Community-1 и локальную Qwen3 через Ollama. Проверь актуальные официальные требования. Community-1 требует совместимого pyannote.audio 4.x; старое ограничение <4.0 не устанавливай. На Windows проверь требования TorchCodec к FFmpeg shared DLL. Отключи облачные функции Ollama и необязательную телеметрию pyannote. Условия доступа Hugging Face и ввод токена выполняет владелец аккаунта; секреты не выводи и не коммить.

Твоя зона: scripts/local-ai/, docs/local-ai/, backend/requirements-ai.txt, backend/tests/local_ai/ и реализации local.py внутри backend/app/services/stt/, diarization/, llm/. Напиши адаптеры существующих абстрактных интерфейсов, с явными настройками путей, устройства и режима вычислений. Импорт модулей не должен сам скачивать или загружать модели. Контракты base.py, общие модели, маршруты API, README в корне и файлы Android не меняй. Недостающий контракт предложи Medet в handoff.

Backend и AI при первой интеграции будут работать на твоём компьютере. Новый отдельный HTTP-сервер для моделей не создавай. API, очередь, объединение timestamps и экспорт интегрирует Medet. Ollama оставь на loopback.

Проверь загрузку моделей и реальное распознавание, diarization и анализ на согласованной несекретной записи с русским, казахским и смешанной речью. Если записи нет, попроси её и продолжай независимые проверки. Не обещай качество без измерений. При недостатке памяти запускай модели последовательно, освобождая ресурсы.

Запиши в docs/local-ai/handoff.md железо, версии, модели/ревизии, команды, параметры конструкторов адаптеров, результаты и ограничения. Модели, записи, .env и окружения в Git не добавляй.

После проверок разрешаю закоммитить только файлы своей роли и отправить ветку codex/local-ai-setup в официальный командный репозиторий. Это заменяет прежнее указание не коммитить и не пушить для этой задачи. В main самостоятельно не сливай и force push не используй. Сообщи ветку, SHA коммита, выполненные проверки и что требуется для интеграции.
```

## Участник Android APK

```text
Создай Android-приложение для HackAlem — локального протоколирования русских, казахских и смешанных совещаний. Результат этой задачи — устанавливаемый APK с полноценным мобильным интерфейсом.

Нас трое: Medet делает backend/API и интеграцию; другой участник подготавливает локальные модели; ты отвечаешь за Android. Официальный репозиторий: https://github.com/BAITC-Hacks/hack-c5aa2345-404-team-not-found.

Проверь локальные изменения и remote по URL. Получи свежий main и прочитай AGENTS.md, README.md, docs/team-workflow.md, docs/api-contract.md и samples/api/meeting-completed.json. Сохрани уже сделанную работу. Работай в codex/android-app. Твои файлы: mobile/, docs/mobile/, docs/screenshots/. Backend, общие схемы и корневые файлы не переписывай.

Стек по умолчанию React Native + Expo + TypeScript, проект внутри mobile/. Если мобильная реализация уже существует, изучи и продолжи её, сохраняя совместимость. Установка необходимых зависимостей, Android SDK и инструментов сборки на этом компьютере разрешена. Проверь официальную документацию и совместимые версии. Нужен самостоятельный APK со встроенным JS, запускающийся без Expo Go и Metro. На Windows используй поддерживаемый путь Expo prebuild/Android Gradle; не полагайся на eas build --local, который не поддерживается там официально. Ключи подписи храни вне Git. APK собирай локально; облачные платные сервисы не подключай автоматически.

Сделай аккуратный, удобный для телефона интерфейс: список встреч; создание встречи и выбор аудио/видео через системный picker; загрузка; состояние обработки; экран результата с резюме, репликами говорящих и поручениями; просмотр источника поручения; скачивание/сохранение DOCX и PDF; настройки адреса backend. Добавь пустые состояния, индикаторы загрузки, понятные ошибки и повторную попытку там, где она безопасна. Учти кириллицу, казахские буквы, клавиатуру, safe areas и небольшие экраны. Первым завершённым сценарием должна быть загрузка готовой записи; запись с микрофона — следующий шаг, если основной сценарий готов.

Используй точные URL и поля из docs/api-contract.md. Пока сервер не готов, разрабатывай на синтетическом примере через явно включаемый деморежим с видимой пометкой. Реальный API-клиент должен быть готов к подключению. Не скрывай ошибки настоящего сервера демоданными. Изменения API предлагай Medet в handoff.

Модели работают на компьютере участника Local AI вместе с backend. В APK нужен изменяемый адрес backend в LAN; localhost на физическом телефоне не подходит. Никаких ключей Hugging Face/Ollama в APK. Для HTTP LAN-демо документируй Android-настройки сети и ограничения тестовой сборки. Облачные AI API не используй.

Проверь сборку, типы, работу интерфейса и установку APK на доступное устройство/эмулятор. Отдельно укажи, какие проверки были с демоданными, а какие с живым backend. Если устройство недоступно, честно укажи это. Сделай реальные скриншоты запущенного приложения в docs/screenshots/ без персональных данных. Подпиши деморежим, если он использован. Не создавай изображения, выдаваемые за скриншоты запуска.

В docs/mobile/handoff.md запиши команды запуска и сборки, версии, путь к APK, SHA-256, API-настройки, результаты проверок, ссылки на скриншоты и ограничения. Корневой README со скриншотами позже обновит Medet. APK передай как артефакт, в Git не добавляй; публикацию Release согласуем отдельно.

После проверок разрешаю закоммитить только файлы своей роли и отправить ветку codex/android-app в официальный командный репозиторий. В main самостоятельно не сливай и force push не используй. Сообщи ветку, SHA коммита, результаты и оставшиеся блокеры. Доведи задачу до доступного результата, не заканчивай одним планом.
```

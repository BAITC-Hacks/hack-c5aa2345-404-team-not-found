# Интеграция существующего Streamlit UI

При подготовке Windows-задачи обнаружена ветка `codex/streamlit-frontend`, commit `160d1e0`. Она основана на более старом состоянии репозитория и содержит интерфейс, тесты и собственные изменения backend. Эти файлы не находятся в текущем main. Код прочитан для сопоставления интерфейсов; его запуск в рамках документационного обновления не проверялся.

## Расхождения с целевым API main

| Операция | Ветка Streamlit | Целевой контракт main |
| --- | --- | --- |
| Загрузка | multipart `audio`, ответ с `meeting_id` | multipart `file`, ответ Meeting с `id` |
| Состояние | `GET /api/meetings/{id}/status` | `GET /api/meetings/{id}` |
| Результат | `GET /api/meetings/{id}` | `GET /api/meetings/{id}/result` |
| История | `meetings`, `next_offset`, limit/offset | `items`, без пагинации MVP |
| Экспорт | `/api/meetings/{id}/download/{format}` | `/api/meetings/{id}/export?format=...` |
| Редактирование задач | PUT с revision | пока не включено в целевой контракт |

Есть и различия в настройках моделей: ветка UI описывает Whisper small и Qwen2.5, а текущий AI-план — выбор Whisper large-v3/turbo и Qwen3 по железу. Нельзя считать эти конфигурации согласованными или проверенными на машине Local AI.

## Порядок работы

1. Сохранить опубликованную UI-ветку и незавершённые изменения участника.
2. Desktop-участнику исследовать упаковку существующего интерфейса в EXE. Не копировать вместе с UI весь изменённый backend без проверки координатора.
3. Составить предложение по согласованию API: адаптация API-клиента к main либо обоснованное обновление общего контракта вместе с backend. Финальное решение принимает Medet до сквозной интеграции.
4. Backend-координатор отдельно рассматривает существующую серверную реализацию и тесты; полезные изменения можно сохранить через согласованную интеграцию.
5. До этого момента запуск UI со своим backend из старой ветки не доказывает совместимость с main. В отчёте всегда указывать ветку/SHA проверенной комбинации.

Эта заметка предотвращает параллельное создание несовместимых API. Она не подтверждает качество моделей и не означает автоматическое слияние ветки.

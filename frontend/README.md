# Meeting Desk · Streamlit

Локальный интерфейс автопротоколирования: загрузка записи, реальные этапы обработки,
редактирование поручений, история, контроль сроков, PDF/DOCX. Внешние скрипты и
шрифты не загружаются, телеметрия Streamlit отключена.

## Структура

```text
frontend/
  app.py                 # точка входа и маршрутизация
  api_client.py          # FastAPI: загрузка, прогресс, история, сохранение
  api_mock.py            # явная автономная имитация backend
  demo_data.py           # обезличенный RU/KZ пример по предоставленным протоколам
  exporters.py           # экспорт демо без запущенного backend
  components/
    layout.py            # локальные стили, светлая/тёмная палитра
    sidebar.py           # навигация и переключатель темы
    meeting.py           # загрузка, прогресс, результаты, редактор и экспорт
    history.py           # поиск и открытие протоколов
    dashboard.py         # KPI, фильтры и сохранение поручений
.streamlit/config.toml   # локальный адрес, размер загрузки, защита и телеметрия
requirements.txt        # зависимости интерфейса и backend
tests/                  # изолированные регрессионные проверки
```

## Быстрый запуск

Нужен Python 3.11 или 3.12. Команды выполняются из корня репозитория.
На Windows вместо `python` можно использовать `py -3.12`, если Python Launcher установлен.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000 --workers 1
```

Во втором терминале:

```powershell
.\.venv\Scripts\python.exe -m streamlit run frontend/app.py
```

Откройте http://127.0.0.1:8501. Для Linux/macOS используйте `.venv/bin/python`
вместо пути `.venv\Scripts\python.exe`. Для другого адреса локального API задайте
`MEETING_API_URL` до запуска интерфейса (по умолчанию http://127.0.0.1:8000).

## Сценарий без нейросетей

Можно запустить только Streamlit и нажать «Посмотреть демо-протокол». Прогресс
помечен «Демо», возвращается готовый JSON из `api_mock.py`; загруженный файл
не используется. Пример содержит саммари производственного совещания, 6 поручений,
русские и казахские реплики, срочные и выполненные задачи.

Проверьте поручения, сохраните исправления, откройте «Экспорт» и нажмите
«Подготовить файлы». История и дашборд покажут этот протокол.
Демо хранится только в сессии браузера; обновление страницы может создать новую сессию.
Настоящие протоколы сохраняются в `backend/data/meetings/` и доступны после перезапуска.

## Настоящая обработка

Для нейросетевой обработки предварительно установите локальные зависимости и веса:

- `faster-whisper`: многоязычная модель, локальный каталог через `WHISPER_MODEL_PATH`
  или заранее заполненный кеш модели `small`;
- `pyannote.audio`: локальный YAML через `PYANNOTE_PIPELINE_PATH`, его модели
  segmentation/embedding также должны быть локальными или закешированными;
- запущенный локально Ollama с подготовленной моделью `qwen2.5:7b-instruct`
  (переопределение через `OLLAMA_MODEL`).

Во время обработки установлен `HF_HUB_OFFLINE=1`: веса не скачиваются из сети.
Качество русского, казахского и смешанного распознавания определяется выбранными
моделями; их точность данным frontend не оценивается.
Если зависимости не готовы, существующий backend возвращает предупреждения и
ограниченный fallback-результат. Эти предупреждения видны в протоколе.

PDF использует установленный шрифт Arial, Segoe UI, DejaVu Sans или Liberation Sans
с кириллицей и казахскими буквами. В Linux установите локально пакет шрифтов
DejaVu Sans. Сетевые шрифты не используются.

## Поведение и ограничения

- Загрузка: AAC, FLAC, M4A, MKV, MOV, MP3, MP4, OGG, WAV, WEBM, до 500 МБ.
  Пустые и неподдерживаемые файлы отклоняются. Наличие читаемой аудиодорожки
  определяется локальным декодером.
- Backend работает с одним worker Uvicorn и одной очередью нейросетевой обработки.
  Проценты означают достигнутые этапы, а не предсказание оставшегося времени.
  Незаконченные задания после перезапуска помечаются прерванными.
- Сохраняются только подтверждённые правки. Ревизии защищают протокол от перезаписи
  устаревшим редактором. При ошибке сохранения черновик дашборда остаётся доступным.
- Точные даты `YYYY-MM-DD` и `ДД.ММ.ГГГГ` участвуют в контроле дедлайнов.
  «До пятницы», «после встречи» и даты без года требуют ручного уточнения:
  приложение не придумывает дату. Красным обозначены просроченные и ближайшие
  (не более трёх дней) невыполненные поручения.
- Поле ссылки Teams/Zoom/Google Meet предусмотрено; присоединение участником
  требует отдельного коннектора, которого нет в текущем backend. Кнопка
  подключения отключена; сейчас используется файл записи.
- Это локальный прототип без авторизации и разграничения доступа. По умолчанию
  оба сервиса слушают только loopback. Публикация в корпоративную сеть требует
  отдельной настройки аутентификации, HTTPS и хранения данных.
- Автоматические рассылки и напоминания не отправляются: срочность отображается
  в дашборде.

## API

1. `POST /api/meetings` — multipart-поле `audio`, ответ 202 с `meeting_id`.
2. `GET /api/meetings/{id}/status` — status, stage, progress, message.
3. `GET /api/meetings/{id}` — результат после завершения.
4. `GET /api/meetings?limit=100&offset=0` — история, `next_offset` для следующей страницы.
5. `PUT /api/meetings/{id}/tasks` — `{"tasks": [...], "revision": 1}`.
6. `GET /api/meetings/{id}/download/docx` и `.../pdf` — экспорт сохранённой ревизии.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Проверки используют временные каталоги и заглушки нейросетей. Они покрывают
асинхронную обработку, валидацию загрузки, ревизии, сохранение при сбоях, экспорт,
удаление/добавление строк, цитаты, фильтры, историю, автономный сценарий и тему.
Они не запускают реальные модели.

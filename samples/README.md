| Файл | Назначение |

Это вручную подготовленные текстовые примеры. Они не являются результатом
распознавания загруженного файла и не доказывают качество моделей.
Демо ссылается на относительный срок «завтра»; без даты встречи календарную дату
вычислять нельзя. «Speaker 1» — метка говорящего, а не установленная личность.

Схема HTTP: [api-contract.md](../docs/api-contract.md). Реальные записи, эталонные
транскрипты участников, результаты встреч и модели в этот каталог не добавляются.
Для оценки качества согласуйте запись и храните её вне Git.
